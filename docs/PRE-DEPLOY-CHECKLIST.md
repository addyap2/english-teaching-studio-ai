# Pre-deployment checklist

- [ ] Install dependencies with npm install
- [ ] Run npm run typecheck and npm run build
- [ ] Run npm test
- [ ] Check the offline sample and teacher/learner views
- [ ] Configure OPENAI_API_KEY and APP_ACCESS_KEY in Vercel environment settings
- [ ] Test an AI-generated lesson with at least 10 questions
- [ ] Check mobile display and print-to-PDF
- [ ] Confirm no keys or personal information are committed
- [ ] Verify Kahoot import format against current Kahoot template
- [ ] Review OpenAI API costs and request limits
